## 📖 项目简介

本项目使用 ESP32 作为主控芯片，通过 DHT22 传感器实时采集室内温度与湿度数据，并根据设定目标值自动控制空调和加湿/除湿设备。系统同时提供 OLED 本地显示、物理按键操作以及基于 WiFi 热点的网页远程控制界面。

---

## ✨ 功能特性

- 🌡️ **实时监测**：每 2 秒采集一次温度和湿度数据
- 🤖 **自动控制**：根据目标值自动控制空调（制冷/制热）与湿度设备（加湿/除湿）
- 🖥️ **OLED 显示**：128×64 屏幕实时显示当前数据与设备状态
- 🌐 **网页控制**：连接 ESP32 热点后，手机/电脑均可访问控制页面
- 🎛️ **物理按键**：支持短按、长按操作，带完整菜单系统
- 🔔 **报警提示**：温湿度偏差过大时 LED 报警灯亮起
- 🛡️ **压缩机保护**：空调最小开停机间隔 3 分钟，防止频繁启停损坏设备

## 🚀 快速开始

### 1. 安装依赖库

在 Arduino IDE 的库管理器中搜索并安装：

- `Adafruit DHT sensor library`
- `Adafruit Unified Sensor`
- `Adafruit GFX Library`
- `Adafruit SH110X`

### 2. 安装 ESP32 开发板

在 Arduino IDE → 首选项 → 附加开发板管理器中添加：
```
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
```

然后在开发板管理器中搜索 `esp32` 并安装。

### 3. 上传代码

1. 打开 `System_Code.ino`（其余 `.ino` 文件会自动加载）
2. 选择对应的 ESP32 开发板型号
3. 点击上传

## 📱 网页控制使用方法

1. ESP32 上电后会自动创建 WiFi 热点
2. 用手机或电脑连接以下 WiFi：

| 参数 | 值 |
|------|-----|
| WiFi 名称 | `ESP32_TH` |
| WiFi 密码 | `12345678` |

3. 打开浏览器，访问：`http://192.168.4.1`

网页支持：
- 查看实时温湿度及偏差状态
- 设置目标温度（16～35℃）和目标湿度（30～90%）
- 切换自动/手动模式
- 独立控制总电源、空调、湿度设备

## 🎛️ 物理按键操作

### 主界面模式

| 按键 | 短按 | 长按 |
|------|------|------|
| Power | 总电源开/关 | 关闭所有设备 |
| Mode | 进入/退出菜单 | 强制退出菜单 |
| Up (+) | 目标温度 +1℃ | 开始快速增加（每200ms+1次，直到松开） |
| Down (-) | 目标湿度 -5% | 开始快速减少（每200ms-1次，直到松开） |

### 菜单项说明

| 菜单项 | 说明 |
|--------|------|
| AUTO/MAN | 切换自动/手动模式 |
| TGT TEMP | 设置目标温度 |
| TGT HUM | 设置目标湿度 |
| AC POWER | 手动控制空调电源 |
| AC MODE | 切换制冷/制热 |
| HUM POWER | 手动控制湿度设备电源 |
| HUM MODE | 切换加湿/除湿 |

## ⚙️ 自动控制逻辑

### 温度控制（迟滞 ±0.8℃）

- 当前温度 > 目标温度 + 0.8℃ → 开启空调**制冷**
- 当前温度 < 目标温度 - 0.8℃ → 开启空调**制热**
- 温度回到目标范围内 → 关闭空调

### 湿度控制（迟滞 ±6%）

- 当前湿度 > 目标湿度 + 6% → 切换为**除湿**
- 当前湿度 < 目标湿度 - 6% → 切换为**加湿**

### 报警阈值

| 参数 | 触发报警 | 解除报警 |
|------|---------|---------|
| 温度偏差 | > ±4.0℃ | < ±2.5℃ |
| 湿度偏差 | > ±20% | < ±10% |
| 传感器故障 | 读取失败 | LED 快速闪烁 |
